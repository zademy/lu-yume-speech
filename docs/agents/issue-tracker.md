# Issue tracker

Issues are tracked in **GitHub Issues** on `zademy/lu-yume-speech`, via the `gh` CLI (`gh issue list`, `gh issue create`, `gh issue view`, `gh label ...`). No other tracker is in use.

## External pull requests

External PRs are **not** part of the triage queue by default. To include them, flip this flag:

```yaml
externalPRsInTriage: false
```

A collaborator's own in-flight PR is never triage work.
