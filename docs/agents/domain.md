# Domain docs

**Single-context** repo: the domain glossary lives in `CONTEXT.md` at the repo root, and architecture decisions live in `docs/adr/` (sequential numbering, newest first in the 4-digit prefix order).

There is no `CONTEXT-MAP.md`. If a second bounded context ever appears, create the map and split per-context `CONTEXT.md` + `docs/adr/` directories.
